# Minecraft Guns — Fabric 1.21.1

Ce projet ajoute le **Pistolet du Chaos** : clic droit pour tirer sur un monstre, 8 points de degats, 32 blocs de portee, 0,4 s entre les tirs, munitions illimitees. Texture incluse.

## Installer le projet sur GitHub

1. Extraire le ZIP sur ton ordinateur.
2. Sur ton depot GitHub, cliquer **Ajouter un fichier > Televerser des fichiers**.
3. Faire glisser **tous les elements extraits, y compris le dossier cache `.github`**, sur la page. NE PAS televerser le ZIP en tant que seul fichier.
4. Cliquer **Commit changes** (Valider les modifications).
5. Dans l'onglet **Actions**, ouvrir **Fabriquer le mod JAR** et la derniere execution verte.
6. Dans **Artifacts**, telecharger **Minecraft-Guns-JAR**, puis extraire le ZIP obtenu pour recuperer `minecraft-guns-1.0.0.jar`.
7. Mettre ce JAR dans `.minecraft/mods` avec **Fabric API pour 1.21.1**, et lancer **Fabric 1.21.1**.
8. En mode creatif, chercher *Pistolet du Chaos*, ou utiliser `/give @s minecraftguns:pistol` avec les commandes activees.

**Important** : ce projet n'a pas encore ete compile ou teste en jeu. Si GitHub montre une croix rouge, envoyer une capture du message d'erreur pour correction.
