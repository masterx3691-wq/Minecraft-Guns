# Minecraft Guns V2 – Fabric 1.21.1

Un mod Minecraft avec pistolet voxel 3D, animation par positions de modèle, 12 balles, recharge R et munitions craftables.

**Commandes :** `/give @s minecraftguns:pistol` et `/give @s minecraftguns:ammo 64`.

**Installer** : Fabric Loader 1.21.1 + Fabric API 1.21.1 + `minecraft-guns-2.0.0.jar` dans `mods`.

**Compiler** : GitHub Actions (Java 21, Gradle 8.12.1), ou `gradle build` dans le dossier projet.

**Attention** : animations à images/poses (recul de culasse, sortie/retour du chargeur), pas une animation squelettique fluide. Code non validé par une compilation locale.
